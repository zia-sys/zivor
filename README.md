# Zivor Marketing Agency Website

A responsive single-page marketing agency website for **NOVA GROWTH**.

## Features
- Responsive marketing agency landing page
- Services, work, process and about sections
- Lead-generation form
- Supabase integration for lead submissions
- Supabase Row Level Security (RLS) protects stored leads from public reads

## Supabase
Project: **zivor GPT**

The frontend uses the Supabase publishable key. Do not add a Supabase service-role key to frontend code.

## Run
Open `index.html` in a browser, or deploy the repository with GitHub Pages / another static hosting provider.

## Lead fields
- Full name
- Business name
- Email
- Phone / WhatsApp
- Service
- Monthly ad budget
- Goals / message
